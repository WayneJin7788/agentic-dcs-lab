# Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone. Be respectful, focus criticism on ideas and evidence, protect confidential operational information, and treat safety concerns as first-class technical contributions.

Unacceptable behavior includes harassment, threats, discriminatory language, publishing private information, knowingly encouraging unsafe deployment, or pressuring contributors to suppress a credible safety/security concern.

Project maintainers may edit, reject or remove contributions and participation that violate these expectations. Report conduct concerns privately to the maintainers through the repository's available contact channel.
