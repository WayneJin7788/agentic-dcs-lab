# Security policy

This repository is research software and must not be deployed in a live control environment.

Please do not publish vulnerabilities that could materially endanger an operational technology environment. Use GitHub's private vulnerability reporting feature for this repository when available. If private reporting is unavailable, open a minimal issue asking maintainers for a confidential reporting channel without including exploit details, credentials, plant identity or topology.

Never attach real DCS exports, credentials, certificates, point lists or network captures to an issue.

The maintainers will acknowledge a complete report when capacity permits. No response-time SLA is offered for this volunteer project.
